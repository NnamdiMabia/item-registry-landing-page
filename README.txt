# iTem Registry Landing Page

## Structure
- index.html — main webpage
- css/style.css — custom styling
- js/script.js — button interactions
- images/logo.svg — logo asset
- README.txt — project notes

## Bootstrap
This version uses Bootstrap 5.3.3 from the jsDelivr CDN for the responsive grid, navbar and utilities. Custom styling remains in css/style.css.

## Run
Open index.html in a browser.
